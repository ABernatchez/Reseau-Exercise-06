# Firewall

Pour lancer le prototype, il faut d'abord lancer le firewall.py et cela va vous afficher le menu principal.

### Menu
Le menu est utiliser en entrant les choix disponible en forme de nombre 
- Le nombre 1 pour continuer
- Le nombre 2 pour une nouvelle partie
- Le nombre 3 pour charger la partie,
- Le nombre 4 pour sauvegarder
- Le nombre 5 pour changer les options
- Le nombre 6 pour quitter

### Mécaniques
Les mécaniques fonctionnelles inclut le menu, pouvoir changer les options (il y en a juste une), choisir les virus, les sauvegardes, l ainsi que le pointage des joueurs.

Les mécaniques que l'on a décider de faire en texte seulement est une grosse partie des rounds. On a fait en sorte que l'on peut simuler quand un joueur meurt ou quand un objet est utilisé, mais c'est quand même limité.
