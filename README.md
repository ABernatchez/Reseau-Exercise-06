Pour lancer le prototype, il faut d'abord lancer le firewall.py par terminal avec la commande & (localisation de python ex: C:\Python314\python.exe) (localisation du fichier ex: c:/Users/Utilisateur/OneDrive/Documents/GitHub/Reseau-Exercise-06/firewall.py), ensuite entrer dans le terminal le nombre 1 pour continuer, nombre 2 pour une nouvelle partie, nombre 3 pour charger la partie, nombre 4 pour sauvegarder, nombre 5 pour changer les options et nombre 6 pour quitter, le menu, pouvoir changer les options, le jeu, les sauvegardes, le pointage ainsi que les statistiques de joueurs sont fonctionnelles.
